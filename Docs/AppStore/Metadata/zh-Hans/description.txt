用清晰的规则，为孩子留出屏幕之外的生活时间，帮助孩子养成合理使用手机的习惯。

ParentalControl 让家长通过自己的手机，管理孩子在所选应用中的使用时间。设置时间限额和时段安排，鼓励孩子完成有益的任务，并在需要时请求查看孩子的位置。

按上学日和周末设置限额

为整周设置统一的每日限额，或为每天分别安排使用时间。例如，上学日少一些，周末多一些。

为睡眠和学习安排时段

选择需要屏蔽所选应用的日期和时间段，帮助孩子放下手机，专注于作业、休息和面对面的交流。

在家长手机上管理

屏蔽或解除屏蔽所选应用，调整今天的可用时间，并查看孩子还剩多少时间。

完成任务，获得奖励

为孩子创建任务，并将额外的应用使用时间设为奖励。孩子完成任务后提交审核，您确认结果后即可给予时间奖励。

查看孩子的位置

请求获取孩子的位置，并在地图上查看。

使用统计

选择日期，查看所选应用的使用时间。详细统计可在孩子手机上通过受 PIN 码保护的家长模式查看。

轻松完成设置

在您和孩子的手机上安装应用，分别选择相应角色，再通过配对码关联两部手机。按照分步引导，开启所需权限、选择要管理的应用，并设置家长 PIN 码。

限制应用需要在孩子手机上授权访问“屏幕使用时间”。如需在后台请求位置信息，请将位置访问权限设为“始终”。

您还可以通过 Apple“家人共享”并为孩子授权家长控制，设置防止删除应用的保护。开始使用时，无需立即完成这项可选设置。
